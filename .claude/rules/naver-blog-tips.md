# 네이버 블로그 글쓰기 팁 & 노하우

네이버 블로그 특화 작성 규칙. 일반 writing-style-ko.md와 별도로 네이버 플랫폼에 최적화된 팁을 관리.

## 네이버 SmartEditor 서식 활용법

### 필수 서식 요소
1. **소제목 (소제목1/소제목2)**: 섹션마다 반드시 사용. 본문과 명확히 구분
2. **구분선**: 큰 주제 전환 시 에디터 구분선 삽입 (텍스트 "───" 아닌 에디터 기능)
3. **인용구**: 핵심 요약, 임팩트 있는 한 줄에 사용
4. **볼드 (Ctrl+B)**: 키워드, 수치, 비교 결과에 적극 사용 (문단당 2-4개)
5. **이탤릭 (Ctrl+I)**: 개인 감상, 부연설명에 사용

### 가운데 정렬 (필수)
- 네이버 블로그는 가운데 정렬이 기본
- 모든 텍스트, 소제목, 인용구 가운데 정렬

### 여백 규칙 (가독성의 핵심)
네이버 블로그는 여백이 많을수록 가독성이 좋음:
- 문단 사이: Enter 3번 (빈 줄 2개)
- 섹션 제목(header) 앞: Enter 4번
- 섹션 제목(header) 뒤: Enter 3번
- 이미지 앞뒤: Enter 3번씩
- 구분선 앞뒤: Enter 2번
- 인용구 앞뒤: Enter 3번
- 리스트 항목 사이: Enter 2번

## 이모티콘 사용 금지

이모티콘/이모지는 AI가 쓴 느낌을 주는 대표적 패턴이므로 전면 금지:
- 소제목, 본문, 리스트 항목 어디에도 이모지 넣지 않기
- 감정 표현은 구어체/말투로 (ㅋㅋ, 진짜, 대박 등은 OK)
- 강조는 **볼드**와 인용구(>)로 처리
- 소제목 예시: "김고은 단발의 비밀" (O) / "✨ 김고은 단발의 비밀" (X)

## 네이버 SEO (C-Rank / D.I.A)

### C-Rank 최적화
- 꾸준한 발행 주기 유지 (주 3-5회)
- 동일 카테고리 집중 (헤어면 헤어, 뷰티면 뷰티)
- 블로그 체류 시간 높이기: 글 길이 500-800자 (핵심만 극도로 간결하게), 이미지 3-5개 (섹션 내용과 정확히 일치)
- 이웃/댓글 소통 활발하게

### D.I.A (Deep Intent Analysis) 최적화
- 키워드 스터핑 절대 금지 — 자연스러운 키워드 배치
- 글의 깊이와 전문성 중요 (얕은 정보 나열 X)
- 독자 만족도 신호: 체류시간, 공감수, 댓글수, 공유수
- 이미지+텍스트 적절히 섞기 (텍스트만 or 이미지만 = 감점)

### 태그 전략
- 핵심 키워드 태그 3-5개
- 연관 키워드 태그 3-5개
- 총 8-10개가 적절
- 너무 많으면 (20개+) 오히려 감점 가능

## 메인 사진 (대표 이미지) 팁

- 블로그 피드에서 첫인상 = 대표 이미지. 클릭률에 직결
- 밝고 선명한 이미지 우선
- 사람 얼굴이 포함된 이미지가 클릭률 높음
- 비포/애프터 비교 이미지도 효과적
- 텍스트가 포함된 썸네일 스타일도 OK (단, 과하지 않게)
- "대표" 버튼으로 대표 이미지 지정 가능

## 글 구조 팁

### 네이버에서 잘 되는 글 구조
```
[임팩트 있는 대표 이미지]

[도입 — 공감/이슈/질문으로 시작 (2-3줄)]

────────────────────

[소제목1 ✨]
[본문 + 이미지]

────────────────────

[소제목2 💡]
[본문 + 이미지]

────────────────────

[마무리 — CTA (댓글 유도, 저장 유도)]
```

### 댓글 유도 CTA 패턴
- "여러분은 어떤 게 더 끌리세요? 댓글로 알려주세요!"
- "혹시 이거 해보신 분? 후기 궁금해요~"
- "댓글로 얼굴형 말해주시면 추천해드릴게요!"
- "이 글 저장해뒀다가 미용실 갈 때 보여주세요 📌"
