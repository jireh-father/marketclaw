# SEO Checklist

Apply these rules when optimizing content. Check every item.

## On-Page SEO

- [ ] Title tag: under 60 chars, primary keyword included, click-worthy
- [ ] Meta description: under 150 chars, includes CTA, naturally mentions keyword
- [ ] H1: one per page, matches title, contains primary keyword
- [ ] H2 subheadings: minimum 3, contain secondary keywords naturally
- [ ] H3 subheadings: used for subsections where appropriate
- [ ] Keyword density: 1-2% for primary keyword (not forced)
- [ ] LSI keywords: 3-5 semantically related terms woven in naturally
- [ ] Image ALT text: descriptive, keyword-relevant, not stuffed
- [ ] Internal links: 3-5 to previously published content
- [ ] External links: 2-3 to authoritative sources (gov, edu, major publications)
- [ ] URL slug: short, keyword-rich, hyphen-separated

## Content SEO

### Search Intent Matching
- Informational ("how to", "what is") → guides, explanations
- Commercial ("best", "vs", "review") → comparisons, reviews
- Transactional ("buy", "pricing", "signup") → product pages, CTAs
- Navigational (brand name) → branded content

### E-E-A-T Compliance
- **Experience**: Include first-person experience, real usage scenarios
- **Expertise**: Demonstrate deep domain knowledge with specifics
- **Authoritativeness**: Cite reputable sources, link to research
- **Trustworthiness**: Be transparent, show both pros and cons

### Advanced
- Featured Snippet optimization: use definition paragraphs, numbered lists, tables
- People Also Ask: address related questions within the content
- Schema markup suggestions: FAQ, HowTo, Article (noted in metadata)

## Platform-Specific SEO

### Naver (Korean)
- Naver C-Rank: consistent posting schedule, quality signals
- Naver D.I.A.: document quality analysis — depth over keyword stuffing
- Naver-specific keywords may differ from Google — research separately
- Blog section titles with Korean keywords

### Google (English)
- Core Web Vitals awareness (keep images optimized)
- Mobile-first content structure
- Passage ranking: make each section independently valuable
- Long-form content (1,500+ words) for competitive keywords
